# نبض العلاقة 💗

متتبع لجودة العلاقة الزوجية — مؤشر صحة، تنبؤ، قرب حميم، ورسوم بيانية.

**بياناتك خاصة بك وحدك (محلية على الجهاز).**

## الميزات

### أساسية
- قلب ثلاثي الأبعاد يتغير لونه ونبضه حسب حالة العلاقة
- تسجيل الخلافات مع الشدة (1–10)
- مؤشر صحة العلاقة (0–100%)
- تنبؤ باتجاه العلاقة (تتحسن / مستقرة / تسوء)
- مسار العلاقة عبر الزمن (رسم بياني)
- تسجيل القرب الحميم وتأثيره الإيجابي على المؤشر
- PWA قابل للتثبيت على الهاتف

### التحسينات (الإصدار 2)
- **تعديل** الخلافات المسجّلة
- **وضع فاتح / داكن**
- رسائل تنبيه لطيفة (Toast)
- تأكيد قبل الحذف
- تحسينات في تجربة المستخدم

## طريقة الاستخدام

1. افتح `index.html` أو انشر على GitHub Pages
2. أضف إلى الشاشة الرئيسية على الهاتف
3. سجّل الخلافات بصدق لترى صورة أوضح

## ملاحظة

المؤشر تقريبي مبني على ما تسجّله فقط، وليس تقييمًا متخصصًا.  
إن شعرت أن العلاقة تتعبك، فالحديث مع مستشار أسري خطوة مفيدة.
